## Slope Calculator 1.2.0

**Help and support, built in.**

- **Help**: What's new, the user guide, **Report a problem** (the contact form opens with the program and version filled in), the error log and the open-source licences.
- **A clear message when something goes wrong.** An unexpected error shows a short notice with **Report a problem**, instead of a grey screen, and is written to an error log next to the program, to attach when you write to us.
- The publisher in Windows' list of programs is now **exceltokml.com**.
- **A start screen** with the icon and name shows the moment you open it, instead of a pause.
- **Signed in already.** Opened from a desktop shortcut or the Start menu, it signs in with the
  Survey Toolkit's account on this PC, if there is one.

Nothing changes in the calculations: slopes, chainage levels, crossfall and the reports work as in
1.1.1, and your saved calculations are kept.

Installed copies offer this update a few seconds after they open. New here? Download
`SlopeCalculator-Setup.exe` below, or open the web app at
https://www.exceltokml.com/slope-calculation/app. If Windows says it protected your PC, choose **More info**, then **Run anyway** (the programs are not signed with a paid certificate yet).
